# Digital Card Framework

A reusable digital collectible framework with a complete collector website. The headless core owns users, wallets, packs, copies, editions, inventories, trades and albums. **Card Atelier** provides beautiful defaults; adopters can replace every page, renderer, layout, theme and host adapter.

## Run the playground

Requires Node **24.14+** and pnpm **11.19.0**.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

Open **http://127.0.0.1:4317**. Switch fictional Rowan/Morgan accounts to test trades. Buy in Discover, reveal in My packs, then inspect and organize your collection. Progress persists in ignored `data/demo.sqlite`; the demo binds loopback. `/alternate` proves a different composition through the public API. Demo imagery is generated by code at runtime; artwork files and game data stay in external content storage.

## Included

| Area | Working features |
| --- | --- |
| Ownership | Stable issuer/subject users, separate inventories, immutable copy identity, opener/time, serial X of Y, provenance and snapshots |
| Economy | Multiple integer currencies, rational conversion values, ledger, independent permissions and operator grants |
| Packs | Multiple lines/products, variable prices, weighted slots, finite editions including 1 of 1, availability windows, optional duplicates and pity |
| Opening | Atomic purchase/allocation, sealed inventory, durable retries, replaceable reveal, skip and replay |
| Collection | Search/filter/sort, favorites, wishlists, duplicate counts, discovery completion and configurable trade-ups |
| Trading | Two visible inventories, drag/drop and Add/Remove, card/currency offers, immutable review, escrow, counters, acceptance, decline/cancel and expiry |
| Marketplace | Admin/player shops, finite card/pack stock, scheduled previews, reviewed purchases, orders and free-entry drop raffles |
| Account rewards | Code-free opening actions, durable delivery, scoped workers, retries and replaceable reward history |
| Albums | Private/public displays, selection/order, drag or arrows, custom layout JSON, isolated CSS, export/import and optimistic editing |
| Presentation | Layered faces, crop/depth/blend/opacity, parallax, gloss/holo/foil masks, emissive effects, backs, orbit/flip/zoom/reset and shared inspection |
| Combinations | Creator-defined grid pieces assemble compatible cards on one 3D stage; arbitrary groups can be compared |
| Content | JSON/YAML catalogs and bulk ID patches, stats/metadata schemas, validation, digest review, atomic publication and CLI |
| Attached data | Owner/public bindings, generated codes, follow/retain/block transfer rules and local single-use state |
| Social | Inventory visibility, blocking, public album browsing, preferences and notifications |
| Operations | OIDC host, encrypted state/sessions, principal/origin controls, limits/quotas, audit, backup/restore checks, key migration and deployment template |

## Embed or replace

```js
// Browser-only entrypoints; no Node imports.
import {createClient} from './src/client.js';
import {mountFramework,element} from './src/ui.js';

const app=mountFramework(container,{
  client:createClient(),
  navigation:'tabs',
  sections:['shop','packs','collection','albums','trades','wallet','custom'],
  theme:{'--dc-accent':'#c4e8ac'},
  viewLabels:{custom:'My experience'},
  backRenderer:copy=>element('span','dc-back-mark','YOUR COLLECTION'),
  views:{custom:(model,context)=>element('section','',model.me.displayName+'’s custom view')}
});
await app.ready;
// On host-route unmount:
app.dispose();
```

Use the core without any UI:

```js
import {CardFramework} from './src/index.js';
import {SQLiteStore} from './src/sqlite.js';

const framework=new CardFramework({store:new SQLiteStore('cards.sqlite',{encryptionKey})});
// Verified server-side authority; never take role/subject from browser JSON.
framework.publishCatalog({role:'admin'},manifest);
const user=framework.registerUser({role:'admin'},{
  provider:verifiedIssuer,subject:verifiedImmutableSubject,displayName:'Collector'
});
```

Public package subpaths expose core, SQLite, HTTP, client/UI, importer, trade controller, trading/collection/inspector/studio/account views, authentication, encryption and contracts. No build step is required. Components can be used independently or replaced; the core does not depend on the website.

## Bulk cards and layered content

Use Creator studio as an authorized operator, or `tools/content.js`. [Moonbridge YAML](examples/imports/moonbridge.yaml) and [JSON](examples/imports/moonbridge.json) show stats, metadata, layers, asset references, rarity/edition and labels. Merge replaces supplied rows by stable ID and retains omitted rows. Publication checks the reviewed digest and catalog version. Existing copies preserve snapshots; published edition identities/caps remain immutable.

Assets live in your storage/CDN. Definitions are public; sensitive reward codes belong in encrypted code pools and variant attachments. Metadata and YAML are data, never executable scripts. See [content authoring](docs/content-authoring.md).

## Production profile

The separate production host uses maintained OIDC verification with PKCE/state/nonce, durable secure sessions, encrypted SQLite and exact-origin/account-bound writes. Follow [production operations](docs/production.md) for issuer registration, secrets, TLS, content storage, recovery and measured small-installation limits.

Real identity-provider configuration, DNS/TLS and protected credentials are required. This repository ships the executable host and deployment template; no live production deployment is claimed. External game wallets, payment/reward delivery, distributed storage and live game integrations remain host extension work. Local binding consumption does not redeem an external reward.
